# Python 小项目集

学习 Python 期间写的四个小项目，全部基于标准库，**无第三方依赖**。

## 项目一览

| 项目 | 说明 | 用到的技术 |
|---|---|---|
| 学生管理系统 | 命令行增删改查 | 面向对象、文件读写、异常处理 |
| 抽卡模拟器 | 原神风格抽卡 | 类、随机数、保底算法 |
| 闰年检测 | 输入年份判断闰年 | 条件判断、循环、异常处理 |
| 字符串编码 | 字母 ↔ 数字互转 | 列表推导、ASCII 转换 |

## 1. 学生管理系统 · `student_management/`

命令行程序，面向对象实现，支持增 / 删 / 改 / 查，数据持久化到文本文件。

### 功能

- 添加、修改、删除、查询学生
- 数据自动保存到 `stu.txt`
- 输入校验：年龄必须是数字、姓名不能为空
- 修改时支持"回车跳过"某个字段

### 运行

```bash
cd student_management
python main.py
```

### 运行效果

```text
--------------------------------------------------------------
  1. 添加学生     2. 修改学生     3. 删除学生
  4. 查询学生     5. 显示全部     0. 退出系统
--------------------------------------------------------------
请输入需要的操作(0~5):5
查询全部学生信息
姓名：张三 | 性别:男 | 电话:13800138000 | 年龄:20 | 其他:测试
```

### 代码结构

| 文件 | 职责 |
|---|---|
| `student.py` | 学生实体（属性 + 序列化） |
| `studentms.py` | 业务逻辑 + 文件读写 + 学号生成 |
| `main.py` | 菜单、主循环、操作分发 |

三层分离：**界面层不碰文件，业务层不碰 `input()`**。

## 2. 抽卡模拟器 · `scripts/模拟抽卡手游修bug后.py`

终端版抽卡模拟，带原石 / 抽卡券 / 保底机制。

### 功能

- 原石与抽卡券资源管理（1 抽 = 160 原石）
- 小保底计数、大保底状态
- 十连 / 单抽
- 抽卡历史记录、出货统计

### 运行

```bash
python "scripts/模拟抽卡手游修bug后.py"
```

### 菜单

```text
=============== 抽卡系统 ===============
1. 查询资源
2. 查询记录
3. 十连
4. 单抽
5. 退出
6. 出货情况
========================================
```

## 3. 闰年检测 · `scripts/判断是否为闰年.py`

输入年份，判断是否为闰年。输入 `9999` 退出。

### 运行

```bash
python "scripts/判断是否为闰年.py"
```

### 效果

```text
========== 检测闰年小程序 ==========
==================================
输入9999退出程序
请输入年份：2024
2024 是闰年
```

## 4. 字符串编码 · `scripts/小脚本.py`

把英文字母转换成 ASCII 序号（a=1, b=2 …），并支持解码还原。

### 运行

```bash
python scripts/小脚本.py
```

### 示例

```text
输入：abc
编码：1 2 3
解码：abc
```
